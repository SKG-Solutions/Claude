# The 25th Hour

The show controller for *The 25th Hour*, a 25-minute talk told on a clock. It's in [`the-25th-hour/`](the-25th-hour/). Open `the-25th-hour/index.html` in Chrome and press → to start.

See [`the-25th-hour/README.md`](the-25th-hour/README.md) for how to run it, the keys, and where photos and films go.
