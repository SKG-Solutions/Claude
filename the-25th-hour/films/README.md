# Films

Drop finished films here with these exact names. MP4, H.264 video, AAC audio, 1920×1080. Reload the page and it plays them instead of the built-in versions or placeholders.

| File | Cue | Length | Without it |
| --- | --- | --- | --- |
| `01-rewind.mp4` | Film 1 · Rewind | about 60s | The built-in Rewind plays |
| `00-daisy-clip.mp4` | Daisy on a scam call | 20–30s | Placeholder with a waveform |
| `02-night-shift.mp4` | Film 2 · The Night Shift | 1:45 | The built-in animatic plays |
| `03-the-scroll.mp4` | Film 3 · The Scroll (your supercut) | 3:00–3:30 | Placeholder phone with the running order |
| `14-instinct.mp4` | Instinct screen recording (optional) | any; it loops | The Instinct card shows the zoomed map |
| `04-lights-out.mp4` | Film 4 · Lights Out | about 60s | The built-in Lights Out plays |

Paths are set in `../cues.js` if you'd rather use other names. Video files in this folder are kept out of git (see `.gitignore`), so copy them to the presenting laptop yourself.

Clips in the supercut: pull them from creators' and brands' official channels, credit them on screen, and check rights if the talk is recorded or shown outside.
